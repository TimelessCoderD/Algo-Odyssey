#### Key Concepts
- Algorithm efficiency depends on how resource requirements grow with input size.
- Running time can be represented as a function of input size, such as `T(n)`.
- The highest-order term dominates when considering asymptotic growth.
- Common growth rates include `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n²)`, `O(n³)`, `O(2ⁿ)`, and `O(n!)`.
