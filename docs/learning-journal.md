# Learning Journal
This journal tracks my learning journey through Java, Data Structures & Algorithms, problem solving, and interview preparation.

The purpose is not to record every topic I study. Topic-specific knowledge belongs in the relevant `Notes.md` files.

This journal records:
- What I am struggling with
- What I understand better over time
- Mistakes I repeatedly make
- Problem-solving habits I need to improve
- Important lessons that change how I approach problems
- Progress in confidence and independent problem solving
---

## Problem-Solving Rules
When I face a programming problem:
1. Understand the problem.
2. Identify the input and expected output.
3. Try to solve it myself.
4. Write the approach in plain English.
5. Trace the approach with a small example.
6. Write the code.
7. Test and debug.
8. Analyze time and space complexity.
9. Only then look at a solution or hint if necessary.
10. Re-code the solution without copying it blindly.
---

## Learning Principles
- Understanding is more important than completing topics quickly.
- I should not memorize solutions without understanding them.
- Struggling with a problem is part of learning.
- I should focus on consistency rather than daily perfection.
- I should revisit concepts that I repeatedly forget.
- I should be able to explain a solution in my own words.
