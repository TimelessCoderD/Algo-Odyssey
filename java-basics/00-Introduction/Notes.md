# Java Introduction

## Computer Program
A program is a set of instructions given to a computer to perform a task.

## Software
Software/application is a collection of programs.

## IDE
IDE = Integrated Development Environment.
Examples:
- IntelliJ IDEA
- Eclipse
- VS Code
An IDE helps us write, run, debug and manage code.

## Basic Java Program
### Class
```java
public class Introduction {
}
```
Java code is organized into classes.

### main()
```java
public static void main(String[] args)
```
The `main()` method is the entry point of a Java application.

### Output
```java
System.out.println("Hello");
```
Prints text to the console.

## 7. Basic Java Syntax
### Java is case-sensitive
These are different:
```text
System
system
SYSTEM
```
### Semicolon
Java statements normally end with:
Example:
```java
System.out.println("Hello");
```
### Comments
Single-line:
```java
// This is a comment
```
Multi-line:
```java
/*
   This is a
   multi-line comment
*/
```
## Key Takeaways

- Java programs are organized into classes.
- `main()` is the starting point of a Java application.
- `System.out.println()` prints output.
- Java is case-sensitive.
- Java statements normally end with a semicolon.
- IntelliJ IDEA is the IDE being used for this project.
