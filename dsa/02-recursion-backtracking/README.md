# Recursion & Backtracking

This chapter focuses on understanding recursion from the fundamentals and gradually building toward backtracking problems.

The goal is not just to solve problems, but to understand how recursive thinking works, how the call stack behaves, how to derive complexity, and how recursion forms the foundation of backtracking.

---

## Learning Objectives

By the end of this chapter, I should be able to:

- Understand what recursion is.
- Identify the base case and recursive case.
- Trace recursive calls using the call stack.
- Write recursive algorithms from scratch.
- Convert recursive code into a recurrence relation.
- Analyze the time and space complexity of recursive algorithms.
- Understand single and multiple recursive calls.
- Understand divide-and-conquer recursion.
- Understand the difference between recursion and backtracking.
- Use the Choose → Explore → Undo pattern.
- Generate subsets, subsequences, permutations, and combinations.
- Solve grid-based backtracking problems.
- Understand constraints and pruning.
- Recognize common recursion and backtracking patterns.
